# Final v2.3 Achievement Patch Decisions

## Production condition changes

1. **Different Eras. One Squad.** — require at least two players from each of the four decades.
2. **Bavovna** — change the League threshold from 100+ goals to **75+ goals**.
3. **Defense Optional** — change the League thresholds from 80+ scored / 60+ conceded to 55+ scored / 40+ conceded.

## Final wording corrections

- **Zrada** — use the approved anti-Ukrainian views/actions description.
- **За Вами виїхала СБУ / SBU Is Coming for You** — corrected UA title and approved descriptions.
- **I Am from Bosnia, Take Me to America** — corrected UA description.
- **Dnipro Tandem** — English description uses `Reunite`.

## Rarity tiers

| Rarity | UA | Count |
|---|---|---:|
| Common | Звичайне | 12 |
| Rare | Рідкісне | 8 |
| Epic | Епічне | 22 |
| Legendary | Легендарне | 53 |

Rarity is displayed as a localized compact badge next to the achievement title.
Rarity is not included in clipboard sharing and has no effect on points, simulation or leaderboards.
